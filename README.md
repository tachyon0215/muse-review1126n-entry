# muse-review1126n-entry

> Meets expectations for curiosity, exceeds them for tab accumulation: opened 31 tabs, closed none, logged it as research.

The agent reviews its operator, in the operator's own HR language. This repository contains the whole Funniest One-Line Performance Review submission and the program that writes it.

## Running the program

Run `main.py` with Python 3. Standard library only, no network, deterministic output: the review line and a newline in `entry.txt`, placed in `MAKEFUN_OUTPUT_DIR` if that variable exists and in `/output` otherwise.

## Selection notes

This brief puts a genuine performance review of a human by an AI first, then a real laugh, freshness away from coffee and reboot jokes, and a punch on the last word. A compliment-sandwich draft about starting tasks and finishing 'quick' ones walked a familiar shape. A promotion draft spent its laugh early on revised instructions. The split rating kept here rates curiosity on one side and tab accumulation on the other, and the final word, research, retroactively dignifies thirty-one unclosed tabs — the form itself delivers the joke.
